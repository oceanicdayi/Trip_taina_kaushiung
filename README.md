爸爸行前貼心小筆記
行車順暢度： 第 2 天調整為中午在市中心的赤崁樓吃午餐，接著一路直直開往安平樹屋與四草（不重複走回頭路），傍晚再開車回花園夜市，整天的交通路線非常完美。
Day 3 停車不挪動： 中午吃丹丹、海之冰到下午搭船去旗津，車子全程停在「蓬萊路停車場」即可，那邊違停抓得極嚴，停好後用走路和搭船最省心。
科工館週一入場： 週一常設展休館，若要去 B1 熱雪天堂（滑雪場），請由「北館電影院入口」或依現場特展專屬告示牌指引進場。

十鼓 週五開放：親子與幼兒專區
幼兒室內體驗館（限 2 – 5 歲）： 週五照常開放。專為幼兒設計的小型室內溜滑梯與球池，非常適合小小孩。
兒童體驗館（限 5 – 15 歲）： 週五照常開放。擁有最經典的室內雙層巨型旋轉滑梯與超大球池，是國小以下孩子放電的絕對核心（記得大人小孩都要穿襪子）。 [1]
魔法列車／五分車（不限年齡）： 週五照常開放。全家人可以一起搭乘露天小火車穿梭在魔法糖廠區，孩子非常喜歡，也是拍照的絕佳景點。 [1]
擊鼓體驗教室： 週五照常開放。有老師在現場帶領，大人小孩可以人手一鼓，體驗親自敲擊十鼓的樂趣。
十鼓擊樂團定目劇表演： 週五照常演出！演出場次固定為下午 15:00（上午 11:00 還有一場）。這個國際級的打擊樂表演非常震撼，是門票內包含的必看重

四草大眾廟停車免費： 下午去四草搭船時，直接把車停在大眾廟兩側的免費大型停車場，不要停在外面路邊，走進去售票處最近。
